# Security Policy

## Supported Version

Security fixes are applied to the latest release on the `main` branch.

## Reporting

Do not include credentials, private capture files, or sensitive network
identifiers in a public issue. Use a
[private GitHub security advisory](https://github.com/Kousiksamanta1/Auto-Sentinel/security/advisories/new)
with:

- affected version and platform
- reproduction steps
- impact assessment
- sanitized logs or captures, when needed

## Scope

Auto-Sentinel is designed for passive wireless discovery and analysis on
networks you own or are explicitly authorized to assess. It does not execute
deauthentication or automate handshake attacks.
